# Smart Intelligent Waste Segregator

This project is an AI-based waste classification system using Convolutional Neural Networks (CNN). 
It classifies waste into categories like plastic, paper, metal, and food.

## Tools & Tech Used
- Python, TensorFlow, Keras
- CNN, Image Classification
- Jupyter Notebook

## Key Features
- Trained a CNN model with labeled waste image data
- Real-time waste classification (prototype smart bin)
- Promotes sustainable waste management
